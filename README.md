# ¡Verbo mío!

The web site of ¡Verbo mío!, a verb game for iPhone, iPad, Mac, Apple TV and Apple Watch, at https://verbomio.app: the [privacy policy](https://verbomio.app/privacy/) and [support](https://verbomio.app/support/). Its [issues](https://github.com/kromych/verbomio/issues) are the app's issue tracker.

The pages are generated by `tools/site.py` in the app's repository from its App Store texts; change them there rather than here.
